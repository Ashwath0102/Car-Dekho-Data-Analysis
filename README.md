# Car-Dekho-Data-Analysis

How to Run

**bash**

`pip install pandas numpy matplotlib seaborn
python car_market_analysis.py`

Make sure your CSV file is in the same folder as the script, or update the DATA_PATH variable. All charts will be saved to the ./output/ folder automatically.

Key Findings from the Analysis

    301 listings across 98 unique models and 44 brands
    Strong correlation (0.879) between Present Price and Selling Price
    Diesel cars sell for ~3x more than petrol on average (₹10.28L vs ₹3.26L)
    Automatic transmission vehicles command ~2.4x premium over manual
    Dealer listings average ₹6.72L vs Individual at just ₹0.87L
    Depreciation averages 36.6% and increases strongly with car age
    79.4% of listings are petrol, 86.7% manual, 64.8% from dealers
